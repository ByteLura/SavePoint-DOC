Quick start

From import to a restored save in about five minutes. You create nothing by hand at any step.

1. Run setup (one click)

Open Tools > ByteLura > SavePoint Pro > SavePoint Pro Home and click Run Setup / Verify Install on the welcome screen.

Setup creates Assets/SavePointPro/Resources/SavePointSettings.asset with a fresh developer key, then writes and reads back a real test save and tells you the result in plain language. Re-running setup later is safe: your key and settings are kept.

Set your own developer key in the Settings tab before you ship. Anyone with the key can open your saves, so treat it like a password.

2. Play the demo (one click)

Click Open Samples on the welcome screen. The Coin Collector demo is copied into your project and its scene opens. Press Play:

  1. On the slot screen, pick a slot and start a new game.
  2. Collect some coins with WASD or the arrow keys. Autosave runs every 20 seconds; the Checkpoint button writes a named checkpoint slot.
  3. Stop Play, press Play again, and Load your slot.

Your coins, position, and playtime are back. That is the product working end to end. Open the home window's Saves tab to see the slot you just made, with its real metadata.

3. Save from your own game

using ByteLura.SavePointPro;

// Build your data (Version is stamped for you)
var data = SavePoint.NewData();
data.SetInt("coins", 42);
data.SetString("heroName", "Ada");
data.SetVector3("position", player.transform.position);

// Save it to slot 0 of the active profile
var saved = SavePoint.Save(0, data, "Level 3 - 42 coins");
if (!saved.Success) Debug.Log(saved.Message);

// Later, or next launch
var loaded = SavePoint.Load(0);
if (loaded.Success)
{
    int coins = loaded.Data.GetInt("coins");
    player.transform.position = loaded.Data.GetVector3("position");
}

Expected problems — an empty slot, a damaged file, a save from a newer build — come back as results with plain-language messages, never as exceptions. The summary string you pass to Save is what the slot screen shows the player.

4. Add autosave

Put a SavePointAutosave component on any GameObject, keep its Data pointing at your SaveData, and it saves on an interval, when the game pauses, and when the player quits. Named checkpoints are one call: SavePoint.Checkpoint("boss-door", data).
