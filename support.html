Support

Before you write

Run the self-check: Tools > ByteLura > SavePoint Pro > SavePoint Pro Home > Diagnostics > Run Self-Check. It exercises the real machinery — encrypted save, load, deliberate damage, backup recovery, a two-step version upgrade, and a mock-cloud sync — in a temp folder and reports each step in plain language. Half of all save problems turn out to be visible right there.

Also check the Overview tab: it shows your setup state, save folder, encryption state, and current data version as they actually are.

Getting help

Support runs through the publisher page for SavePoint Pro on the Unity Asset Store — use the support contact listed there. (Keeping one support door means nothing gets lost between inboxes.)

Support: bytelura@gmail.com.

Include these in your message and your answer will be faster:

  • Your Unity version (2022.3 LTS or Unity 6) and SavePoint Pro version.
  • The six self-check results, copied from the Diagnostics tab.
  • What you expected, what happened instead, and the exact result message the API returned (SaveResult and LoadResult messages are written to be pasted into a support mail).
  • Whether the problem reproduces in the Coin Collector demo.

What support will not ask for

Your developer key or your players' save files. Never send either. If a save file itself is the problem, send the self-check results and the slot's metadata (the Saves tab shows it) — that is enough to work from.
